这是一个用来记录各种小技巧的合集。

平时读源码、翻博客、刷推特的时候，经常会碰到一些很小但很妙的写法。它们大多不值得单独写一篇长文，但又确实值得记下来，免得下次遇到又得从头想一遍。于是我把它们收集在这里，每个技巧作为一篇 sub blog。

每篇都尽量简单：**之前的写法差在哪，这个写法好在哪**，配一小段能看懂的代码就够了。

代码统一用 TypeScript，重点在思路，语言只是载体。
