这里先分享两个写作类 Skill。一个从作品中提炼可复用的创作技法，一个在成稿后检查和修补常见的 AI 化表达；后续遇到有意思的 Skill 会继续补充到这个系列。

## 文风.skill：提炼作品的写作技法

[XTmingyue/wenfeng-skill](https://github.com/XTmingyue/wenfeng-skill) 把自己定位为“作品写作 Skill 蒸馏器”。输入一部有权处理的小说文本或文件路径，它不以复述剧情、摘抄原句为目标，而是尝试把作品背后反复出现的创作方法整理成一个可调用的 `SKILL.md`。

它关注的并不只是词语和句式，而是七个层面：叙事模型、语言指纹、母题与意象、人物塑造、情节技法、风格边界，以及分析时应保持的诚实边界。项目对一条规则有三个要求：它要在原作中重复出现，能在新场景中指导写作，并且不是任何小说都适用的空泛建议。这个筛选标准很重要——没有它，最后得到的往往只是一张“多描写、多冲突”的写作清单。

适合把它当成一个分析器，而不是模仿器。比如读完一部喜欢的小说，可以请它总结开篇如何建立压力、人物关系如何升级、转场如何控制节奏；随后再让生成出的 Skill 写一个全新的场景。这样保留下来的是抽象技法，而不是原作的措辞、段落或可替代原作阅读的情节。

项目 README 给出的安装方式是：

```bash
npx skills add XTmingyue/wenfeng-skill
```

> [!NOTE]
> 处理受版权保护的作品时，先确认自己拥有处理文本的权利。生成的 Skill 应只保存抽象规则，不应保存原文片段或可替代原作的详细复述。

## De-AI Prompt Enhancer & Writer Booster：成稿后的保真修订

[OUBIGFA/De-AI-Prompt-Enhancer-Writer-Booster-SKILL](https://github.com/OUBIGFA/De-AI-Prompt-Enhancer-Writer-Booster-SKILL) 面向中文写作，提供两种模式：`good-writing` 用于从参考文章中整理一种作者风格；`de-AI-writing` 则更接近一个保真润色补丁，在不改动核心信息的前提下调整措辞、句式和段落节奏。

后者特别适合信息综述、科普和翻译后的初稿。它将常见的模板化表达拆成 24 项检查项，并配有段落、句式与标点的约束；仓库还提供 Node.js 与 PowerShell 的风格审计脚本。与其让模型笼统地“写得自然一点”，不如先明确要检查什么，再让它逐项修订。

不过，“去 AI 味”不等于把文章换成一堆口语词，也不是可以被某个分数完全证明的结果。真正值得保留的约束是：不新增未经核实的事实、不丢失原有论点、不为了显得生动而改变语气和立场。这个 Skill 的说明也承认不同模型和不同轮次的效果会有差异，因此更适合把它放在人工复核之前，而不是当作最终发布按钮。

使用时可以把仓库中的 `good-writing` 或 `de-AI-writing` 目录放进项目的 Skill 目录；前者需要有代表性的参考文章，后者则适合直接作用于已有草稿。一个实用流程是：

1. 先自己列出文章的事实、结论和不能改动的术语。
2. 用 `de-AI-writing` 做一轮保真修订，重点处理重复的结构和空泛的评价。
3. 对照原稿核查事实、数字、链接和语气；必要时再运行仓库提供的风格审计脚本。

这两个项目分别处在写作流程的不同位置。`wenfeng-skill` 更适合整理“我希望怎样写”；De-AI Prompt Enhancer 更适合处理“这篇已经写出的文字，哪里显得模板化或不够顺”。前者影响选材、结构与叙事，后者谨慎处理表达层。
